HTML Text Formatting

Bold text is created using the <b> tag. It makes text visually bold with no extra meaning.

Strong text is created using the <strong> tag. It also makes text bold, but it signals that the text is important.

Italic text is created using the <i> tag. It's often used for technical terms or foreign words.

Emphasized text is created using the <em> tag. It italicizes text and gives it stress emphasis.

Underlined text is created using the <u> tag.

Highlighted text is created using the <mark> tag. It's useful for marking relevant text.

Small text is created using the <small> tag. It reduces the font size.

Deleted text is created using the <del> tag. It shows a strikethrough on removed content.

Inserted text is created using the <ins> tag. It underlines newly added content.

Subscript is created using the <sub> tag, like in H2O.

Superscript is created using the <sup> tag, like in E = mc2.
